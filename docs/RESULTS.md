# Evaluation results

Generated by `python evaluate.py` (fixed seeds, so rerunning gives the same numbers). Train stream: 40,000 txns; test streams: 30,000 txns, different seed and different simulated customers.

> **Read this honestly.** The data is synthetic and the fraud patterns come from the same generator the rules were written against, so scores are optimistic. What transfers is the *comparison*: how each component contributes, how precision falls as fraud gets rarer, and how a supervised model behaves on attacks it has never seen.
