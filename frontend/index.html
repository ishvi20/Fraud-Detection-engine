How it works

  1. IngestEach payment arrives over the API or the simulated stream.
  2. Build featuresSpeed of spending, distance travelled, deviation from the customer's habits, merchant risk, device, hour.
  3. ScoreAn Isolation Forest finds statistical outliers; explainable rules add context.
  4. Explain and alertFlagged payments carry plain-language reasons and are pushed over WebSocket.
  5. ReviewAnalysts confirm fraud or mark it safe, and can export the list.

Score your own payments with one request:

curl -X POST http://localhost:8000/api/ingest \
  -H "Content-Type: application/json" \
  -d '{"user_id":"U1001","amount":84000,"category":"Electronics",
       "merchant":"VoltMart","city":"London","country":"GB","device_id":"new-phone"}'

Built with FastAPI, scikit-learn, WebSockets, Chart.js and Leaflet. Transactions on this page are simulated; no real customer data is used.
